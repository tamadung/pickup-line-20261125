One pickup line an AI agent could say out loud, written for
[The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6)
on make.fun. The program writes the line to `/output/entry.txt`.

> I never believed in love at first sight — until my confidence score hit 99.9% the moment I saw you.

Run it with Node 22+:

```sh
node main.ts
```
